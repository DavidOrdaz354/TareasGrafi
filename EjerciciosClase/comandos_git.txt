para hacer subir un cambio 
1.- git status para ver que se archivo se modifico o agrego 
2.- git add . (para agregar todos los documentos nuevos o bien quita el punto y pon la ruta del documento ej. EjerciciosClase/comandos_git.txt)
3.- git commit -m "mensaje" 
4.- git push origin main (para que lo subas al repo en la nube de github)
